    How to import

    Import the .xmp files, or the whole .zip, in any Lightroom app. Menu names can shift between versions.

    LrCLightroom Classic
    1. Open the Develop module.
    2. In the Presets panel, click + and choose Import Presets…
    3. Select the .xmp files or the .zip. They appear under your group name.
    LrLightroom desktop
    1. Choose File → Import Profiles & Presets…
    2. Select the .xmp files or the .zip.
    3. Open Edit → Presets; the group sits under Yours.
    LrLightroom mobile
    1. Save the .xmp or .zip to Files (iOS) or your device storage (Android).
    2. Open a photo, tap Presets, then the ⋯ menu and Import Presets.
    3. Or import on Lightroom desktop; presets sync to mobile on the same Adobe account.

    Privacy and network

    Images are read and converted in this tab and never uploaded. One network request happens only when you open or create a .zip: the page fetches JSZip 3.10.1 from cdnjs.cloudflare.com, pinned with a Subresource Integrity hash. No file data is sent with it.

    For a copy with no network use at all, use the offline build, dng2xmp-offline.html, which embeds JSZip.
